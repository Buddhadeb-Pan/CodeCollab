## Getting Started

### Backend Setup

1. Navigate to the backend directory:
   ```bash
   cd backend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server (with nodemon):
   ```bash
   npm run dev
   ```

4. Start the production server:
   ```bash
   npm start
   ```
